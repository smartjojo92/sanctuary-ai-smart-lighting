# Sanctuary AI – Video Demonstration

This folder contains the narrated demonstration of my AI-powered smart lighting prototype.

The video demonstrates natural-language lighting control using Home Assistant, Ollama, and Qwen3.

**Demonstrations include:**
- AI-controlled lighting dimming
- Movie Mode activation
- Bedtime automation
- Multiroom lighting control

**Video:** [Watch or Download Sanctuary Portfolio](Sanctuary_Portfolio.mp4)

*Note: This prototype uses simulated lighting devices.*
